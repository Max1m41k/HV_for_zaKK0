# TriadVisual

Косметический Fabric-клиент для Minecraft **1.21.11** (yarn `1.21.11+build.6`). Только визуал и косметика: никаких читов, X-Ray, авто-аттак и подобного в сборке нет и не будет.

**144 модуля** + встроенные функции, которые нельзя выключить.

## Сборка

Нужен JDK 21. В `build.gradle` две маппинг-конфигурации, версия выбирается свойством `mc`, по умолчанию стоит `1.21.4`, поэтому для этого дерева указываем её явно:

```
gradlew compileJava   -Pmc=1.21.11   # только проверка типов
gradlew remapJar      -Pmc=1.21.11   # готовый mod jar в build/libs
```

Полная сборка требует ключа разработчика: задача `genHvSignature` обращается к серверу подтверждения и кладёт в сборку маркер подлинности. Без переменной окружения `HOLY_ADMIN_TOKEN` (ключ в код не вписан) сборка останавливается с внятной ошибкой — это защита от чужих сборок, а не баг.

## Управление

* `RightShift` — открыть GUI настроек, `Esc` — закрыть.
* Колёсико — прокрутка колонок, ЛКМ по модулю — вкл/выкл, ПКМ — его настройки.
* Быстрые команды через `.`: `.bind`, `.gps add|remove|s`, `.macros list`, `.savecfg`, `.loadcfg`, `.cfg` и `.cfg restore <№>`, `.media`, `.hub`.
* `Ctrl` + перетаскивание — редактор HUD: сетка, направляющие, `СБРОС` позиции, стрелки — точный сдвиг.
* `Esc` в игре → «Запись» и «Записи»: просмотр клипа с таймлайном, `Space` — плей/пауза, `M` — свободная камера, `R` — нарезка киллов.
* Сервер может скрыть часть функций: при входе на внешний сервер мод спрашивает список через канал `liteapi:feature-control` и до ответа держает всё скрываемое выключенным.

## Встроенные функции (не выключаются)

* Пинг цифрами в TAB-листе и пилюля «ник + HP + пинг» над игроками, краснеющая при ударе.
* Номера слотов хотбара, маркер трёх точек у настраиваемых модулей, иконки перед названием модуля.
* `EnchantGlow` — подсветка зачарований на предметах.
* Метки `.gps` и авто-метки активных ивентов по `/event`, маркер «треугольник вниз» под прицелом.
* Стеклянный (мыльный) фон панелей HUD, размытие, палитра GUI.
* Осмотр оружия на `G`, звук возрождения Re:Zero, блокировка `/hub` в PVP-режиме.
* Быстрые команды через `.`, меню HolyWorld и аккаунты в один клик на главном экране.
* Цены лотов аукциона в HW-coin под наведением.
* Значок TNT над хотбаром, если рядом (20 блоков) подожгли динамит: показывает, сколько осталось до взрыва, и считает fuse/радиус кастомного TNT по пакету взрыва.
* `BeatPulse` — интерфейс «дышит» в ритм музыки; в тишине эффект нулевой.
* `ConfigGuard` — конфиг пишется атомарно, перед перезаписью остаётся копия в `visualmod_configs/backups/`; битый файл откладывается и заменяется последней пригодной копией.
* Редактор HUD (зажать `Ctrl` и тянуть элемент): сетка, направляющие, рамка выделения, `СЕТКА`/`СНАП`/`ШАГ`/`СБРОС`.
* Громкость и ритм берутся из системного WASAPI-метра и фильтруются по «длительности», поэтому удары меча и взрывы не дёргают визуал.
* Значок TriadVisual на окне игры, в заголовке и на кнопке панели задач; ярлыки лаунчера допроходят там же, отключается пустым `%APPDATA%\HolyVisuals\off`.
* Перетаскивание аудио в окно: `.wav` копируется в `Holy-visual info/music` и сразу играет, остальные форматы мод честно называет в чате.
* Совместимость с Iris: мир-эффекты не пишутся в проход теней шейдер-пака, поэтому с активным шейдером нет чёрных плоскостей в карте теней.

Исходники публикуются для обзора и изучения. Сборка и перепубликация без ключа разработчика не проходят: маркер подлинности проставляется на этапе сборки.
